# Churnwise

**Predict who will leave, understand why, and know exactly how to keep them.** Churnwise is an agentic customer-retention system: a machine-learning model flags at-risk customers, an AI agent explains the drivers behind each prediction, and a RAG pipeline turns those insights into tailored retention strategies.

## Features

- **Churn prediction:** a Random Forest classifier with an **82.7% ROC-AUC**
- **Explainable risk drivers:** SHAP analysis shows _why_ each customer is likely to churn
- **Agentic reasoning:** a multi-stage agent interprets those drivers before recommending action
- **RAG-powered strategies:** retrieves proven retention plays from a curated tactical knowledge base
- **Two strategy modes:**
  - **Advanced Agent:** structured strategy reports with reasoning logs and business disclaimers
  - **Llama-3 synthesis:** conversational strategies generated by Llama-3-70b via Groq
- **Cyberpunk dashboard:** a glassmorphic Streamlit interface

## How It Works

```
Customer data
      │
      ▼
Preprocessing ──► Random Forest ──► churn probability
                        │
                        ▼
                SHAP risk drivers
                        │
                        ▼
      Agent + RAG (FAISS knowledge base)
                        │
                        ▼
        Tailored retention strategy report
```

## Getting Started

### 1. Install

```bash
git clone https://github.com/Sayed-jibril/churnwise-retention-agent.git
cd churnwise-retention-agent
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Add your API key (recommended)

The Llama-3 mode needs a Groq key. Create a `.env` file in the project root:

```bash
GROQ_API_KEY=your_groq_api_key_here
```

Get a key at [console.groq.com](https://console.groq.com/). Keep `.env` out of version control.

### 3. Run

```bash
# Train and validate the model
python src/train.py

# Launch the dashboard
streamlit run app.py
```

## Model Performance

Training uses **5-fold cross-validation** for robust estimates:

| Metric   | Score  |
| -------- | ------ |
| Accuracy | ~78.8% |
| ROC-AUC  | 82.7%  |

**Top churn drivers:** `Contract_Month-to-month`, `TotalCharges`, `Tenure`

## Deployment

On **Streamlit Cloud**, don't upload a `.env` file. Add `GROQ_API_KEY` in the app's **Settings → Secrets** instead.
